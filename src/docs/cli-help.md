Available commands:
  - list (ls) [session | tab] : List all active sessions
  - attach (a) <session-name> : Attach to session `session-name`
  - detach (d)                : Detach from current session
  - switch (s) <tab-name>     : Switch to tab `tab-name`
  - status                    : Show current status
  - help                      : Show this help message
  - exit (quit, q)            : Exit the CLI
